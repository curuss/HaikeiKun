# 背景君

デスクトップを全て覆い隠し、登録したショートカットから必要なファイルやアプリだけを開いて、スクリーンショットを撮れる Windows 10 / 11 用の小さなアプリです。
散らかったデスクトップや関係のないウィンドウを写さずに、見せたいものだけを撮影できます。

- デスクトップとタスクバーを、単色または画像で全て覆い隠します
- 登録したショートカットだけを、等間隔に並べて表示します。そこから必要なファイルやアプリだけを開けます
- 登録したキーで撮影できます（画面全体、手前のウィンドウ、指定した範囲）
- インストール不要です。exe ひとつで動き、設定ファイルも作りません

## ダウンロード

https://github.com/curuss/HaikeiKun/releases/latest から `HaikeiKun.zip` をダウンロードしてください

## 使い方

### 準備

1. `HaikeiKun.zip` を展開します
2. 出てきた `背景君.exe` を、デスクトップなど好きな場所に置きます
3. ダブルクリックすると、設定画面が開きます

### 設定画面

- 「背景」タブ：背景を単色にするか画像にするかを選びます。終了キーもここで変えられます
- 「ショートカット」タブ：背景の上に並べたいショートカットやファイルを登録します。一覧へドラッグしても登録できます
- 「撮影」タブ：撮影キー、撮影する範囲、保存先を決めます
- 「設定の保存」タブ：設定の保存についての注意書きと、初期設定に戻すボタンがあります

設定が済んだら「背景を表示」を押します。設定画面があるモニターが、背景で覆われます。

### 背景を表示している間

- 並んだショートカットをダブルクリックすると、そのアプリが背景の手前に開きます
- F2 キーで撮影します。画像は「ピクチャ」の中の「背景君」フォルダに保存され、クリップボードにも入ります
- 撮影する範囲を「指定した範囲」にすると、背景の上に枠が出ます。枠の辺や角を引っ張ると大きさが変わり、左上の大きさ表示を引っ張ると枠ごと動きます。枠は撮影には写りません
- 「登録したショートカットを写さない」がオンのとき、並んだショートカットは撮影に写りません

### メニュー

背景を右クリックすると、背景君のメニューが出ます。並べたショートカットに背景君自身を登録しておくと、それを起動してもメニューが出ます。

- ウィンドウの一覧：開いているウィンドウが並びます。押すとそのウィンドウが手前に出ます。最小化しているもの（「最小化中」と表示）は、元の大きさに戻ります
- 撮影する
- 設定画面を開く（背景はそのまま）：背景を出したまま設定を変えられます。「反映して背景に戻る」か設定画面の × で、変更がその場の背景に反映されます。開いているアプリはそのまま残ります
- 背景を閉じる

### 終わるとき

次のどれかで背景が消え、設定画面に戻ります。

- 背景をクリックしてから F11 キーを押す
- 画面の上部中央にポインタを当て、出てきた × を押す
- メニューの「背景を閉じる」を選ぶ

撮影キー（F2）と終了キー（F11）は、設定画面で別のキーに変えられます。

## 初回起動時の警告について

署名のない個人製アプリのため、初回起動時に「WindowsによってPCが保護されました」と表示されることがあります。
その場合は「詳細情報」をクリックし、「実行」を押してください。

## 設定の保存について

設定は `背景君.exe` 自身に付け足して保存します。設定ファイルは作りません。そのため、次のような動きになります。

- exe を捨てると、設定も一緒に消えます
- exe を新しい版に差し替えると、設定は初期設定に戻ります
- 保存できるのは NTFS 形式のディスクだけです（パソコン本体のディスクは、ふつうこの形式です）
- USB メモリやクラウドのドライブなどでは保存できず、設定はその回かぎりになります。その場合は、設定画面のタイトルにその旨が表示されます
- そうした場所へ exe をコピーすると、設定は付いていきません。コピーのときに「プロパティを含めずにこのファイルをコピーしますか？」と表示されたら、設定が付いていかないという意味です。「はい」を押して問題ありません
- 初期設定のままのときは、何も保存しません

## アンインストール

`背景君.exe` を削除するだけです。設定は exe に付いているので、一緒に消えます。
撮影した画像（「ピクチャ」の中の「背景君」フォルダ）は残るので、不要なら削除してください。
